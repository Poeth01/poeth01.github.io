## 📦 What This Application Does

Xemu Desktop is a Windows utility that works alongside your Xemu emulator setup. It does not replace Xemu and it does not change how your games run. Instead, it acts as a local assistant that organizes the files sitting around your emulator:

- It watches over your save-state folders so nothing gets scattered across your hard drive.
- It opens config and BIOS-path files in a readable, plain-language view.
- It manages photo albums, keeping screenshots and images grouped and easy to browse.
- It works entirely on your own computer. Nothing is uploaded anywhere.

Think of it as a filing cabinet for the files your emulator depends on. You point it at a folder, and it keeps everything labeled and in the right drawer.

## ⚙️ Config and BIOS-Path Files

Config files control how your emulator behaves, and BIOS-path files tell it where to find the system files it needs. Both are usually plain text, which makes them easy to break by accident.

xemu-desktop gives you a safer way to look at them:

- Open a config file and see each setting on its own line with a short explanation.
- Change a value using a simple field instead of editing raw text.
- Save your changes with a confirmation step, so a stray keystroke never overwrites anything.
- Store your BIOS folder path once and reuse it whenever a file asks for it.
- Keep a backup copy of the previous version automatically before any save.

That last point matters. If a change does not behave the way you expected, you can go back to the earlier version in one click.
